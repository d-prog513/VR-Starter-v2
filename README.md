# -Vr parkour pvpve
An experimental VR exploration and climbing prototype
Desktop and Quest movement.
Smooth/snap turning and speed settings.
Jumping, air steering, and platform collision.
Ledge grabbing, turning, pull-down ascent, and launch.
Planted grip visuals and optional hints.
XR-aimed returning knife.
Practice orb and summit dummy with hit feedback.
limits: no sound yet, placeholder hands without animated arms, no multiplayer/body avatar, and incomplete collision coverage for decorative scenery.
